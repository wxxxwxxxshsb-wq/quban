# Privacy 2.4.1

2.4.1：提速与表情包。启动改为“先显示、后校验”，服务器慢或刚醒时也能立刻打开；Service Worker 改为缓存优先；手机版与电脑版样式分开（`mobile.css` / `desktop.css`）；气泡与头像改用更省力的像素画法；新增原创像素小鳄贴纸 12 张。

像素深色版本：语音消息、应用锁与密室、隐私体检、阅后即焚，以及一整套日常工具。完整说明见 [更新说明-2.4.1.md](更新说明-2.4.1.md)。

## 2.4.0 更新内容

- **语音消息**：按住录音、左滑取消、上滑锁定、停止后试听再发；气泡里是像素波形，可点播放、切 1× / 1.5× / 2× 倍速；发送方可选择同时附带本机转写的文字（设备支持语音识别时）。单条上限 5 分钟 / 5 MB。
- **聊天**：表情印章（心、星、勾、闪电、问号、叹号）、回复引用、转发、为所有人删除、仅从本机删除、聊天列表钉住 / 静音 / 未读、好友请求确认、屏蔽、聊天详情页。
- **阅后即焚与限时照片**：每个聊天可设 1 小时 / 24 小时 / 7 天 / 30 天；也可设置新聊天的默认时长。限时照片只能被对方查看一次，查看后服务器立刻销毁文件。
- **应用锁与密室**：4 位 PIN（只保存加盐哈希）、自动锁定时间、切换应用时遮挡画面、通知隐藏内容；重要聊天可放进“密室”，进入前需再次输入 PIN。
- **隐私体检**：按你的设置打 0–100 分，并给出一键“去设置”的建议。
- **更多**：“今天”并入“更多”；新增提示词优化器、备忘与提醒、收藏与文件、文档扫描（拖角裁剪、透视矫正、增强 / 黑白、多页 PDF）、快捷翻译（文字 / 语音 / 图片取字）、语音转文字、全局搜索（聊天、收藏、备忘、提示词）、定时发送、隐私联系卡（含扫一扫）。
- **成就与回顾**：等级、本周打卡、9 枚徽章、每周回顾。
- **外观**：5 种主题色、聊天背景、文字大小、减少动效、启动锁扣动画开关；免打扰时段；导出我的数据；清理本机缓存。
- **服务器**：消息有了编号；新增音频媒体类型、表情印章、删除、阅后即焚、限时照片、屏蔽、好友请求、聊天摘要、数据导出等接口；旧数据自动兼容，无需迁移。

## 之前版本的内容（2.3.8）

暖黄像素视觉版本，包含静态首启锁标动效、英文品牌字、账号验证与设置功能。

## 更新内容

- 首次冷启动显示一次锁扣合上的短动画；页面仍在后台时切回不重播。没有进度条或额外光效。
- 黄色 Privacy 锁标同步用于应用图标、网站图标和手机桌面图标。
- 聊天区采用石墨深色、柔和像素点纹理与克制的金黄色强调色，左右金色边线与暖黄消息气泡呼应品牌。
- 注册与登录都使用一个向下展开的方式选择账号密码、邮箱、手机号或 Google；默认是账号密码。Google 注册会验证 Google 账号并创建 Privacy ID；邮箱/手机号仍按原有验证码流程验证。
- 设置包含通知预览、语言选项、联系方式绑定与账号删除。
- “输错密码后自动删除账号”默认关闭；启用后需要本人输入密码确认，并可设置错误次数。
- 浏览器脚本错误会关联请求码记录到服务器诊断日志。
- Google 登录凭证由服务端验证签名、有效期、受众和已验证邮箱；启用步骤见 [Google 登录配置.md](Google登录配置.md)。
- 未登录时显示登录入口；游客可浏览首页及精选离线小游戏，AI、好友聊天、备忘录、完整游戏和个人数据需登录。
- 登录可分别使用 Privacy ID、邮箱或国际手机号 + 密码；国家/地区区号由下拉选择。
- AI 状态可在聊天页查看。Render 必须配置 `GH_MODELS_TOKEN` 或 `ANTHROPIC_API_KEY`，否则模型无法回答。
- 聊天改为 Telegram 式的两栏/单聊布局，加入好友在线状态、聊天内搜索、贴纸面板、相机拍摄和本机照片/视频选择。
- “更多”页汇集日常工具、游戏和新增功能：全局搜索聊天/本地备忘/待办、定时发送文本消息、语音转文字草稿、Privacy ID 联系二维码。
- 联系二维码由本机生成，默认只包含 Privacy ID；扫码后需手动确认添加。语音识别由浏览器支持情况决定，使用前提示语音识别服务可能处理音频，识别结果不会自动发送。
- 定时消息仅支持已添加好友；服务运行时会按计划发送，重启或平台休眠可能造成延迟。Render 免费实例可能休眠，数据持久化仍需配置持久磁盘。
- 照片、视频通过私有媒体接口发送给已添加好友；单个文件上限 5 MB，每条消息最多 6 个。媒体文件保存在 `DATA_DIR/media`，读取时校验会话成员。
- 聊天媒体和现有消息一样由应用服务器处理；当前版本没有端到端加密，请勿发送密码或高度敏感资料。

## 运行

安装 Node.js 18 或更新版本，在项目根目录执行 `npm start`。根目录必须保留 `server.js`、`package.json` 和 `public/`。

邮箱和短信验证码需要配置服务商密钥，具体见 [验证码配置.md](验证码配置.md)。真实密钥只填写在 Render 的环境变量中，不要上传到 GitHub。

Google 登录需要设置 `GOOGLE_CLIENT_ID`，具体步骤见 [Google 登录配置.md](Google登录配置.md)。

如需在 Render 长期保存账号、好友、消息、设置和聊天媒体，请挂载持久磁盘并设置 `DATA_DIR=/var/data`。未配置持久磁盘时，平台重启或重新部署可能清除本地数据和上传媒体。
