# 趣伴 QuBan 2.2.2（网页 / 手机桌面版）

聊天加好友 · AI 助手「小伴」 · 7 个小游戏 · 好友实时五子棋 · 多条备忘录 · 每日打开日志 · 待办/计算器/番茄钟 · 每日打卡与成就

## 2.1–2.2.2 功能更新
- 备忘录支持多条记录、搜索、置顶和自动保存；原有单条便签会自动迁移为第一条备忘。
- “我的”页面记录每日打开次数和首次打开时间，最多保留最近 180 天。备忘录和打开日志保存在当前设备/浏览器，不会跨设备同步。
- 新增同屏双人五子棋，可轮流落子和悔一步；原有人机五子棋仍保留。
- 全新黑银金属立体 X 标志，带趣伴专属的冰蓝菱形细节；每次冷启动播放同色系电影感动画，切到后台再回来不重播；游戏大厅加入无 AI 的好友实时五子棋。
- 账号登录时记住上次昵称；密码仍由浏览器密码管理器保管，服务端只保存加盐哈希。
- 后端支持 `DATA_DIR`，可把账号、好友、消息和对局保存到 Render 持久磁盘。
- 刷新 PWA 缓存版本，部署更新后会下载新版图标和前端资源。

## 账号长期保存（Render）
当前 Render 免费 Web Service 的本地文件会在重启或重新部署时清空，因此账号和会话可能丢失。Render 免费服务不支持持久磁盘。要长期保留账号数据：
1. 在 Render 将 `quban` 服务升级到支持磁盘的付费实例。
2. 在该服务的 **Settings → Disks** 添加磁盘，Mount Path 填 `/var/data`。
3. 在 **Environment** 添加 `DATA_DIR=/var/data`，保存并重新部署。

此后新写入的账号、好友、消息和在线对局数据会放到持久磁盘。已经被旧免费实例清掉的数据无法从新代码恢复；切换前后原有数据也不会自动搬到磁盘。

## 从现有 GitHub 仓库更新
如果仓库里应用项目放在 `quban/` 子目录：先把更新包解压，在 GitHub 的仓库 `quban/` 目录上传并覆盖 `server.js`、`package.json`、`README.md`、`.env.example`；再进入 `quban/public/`，上传并覆盖更新包中 `public/` 里的文件。上传时选中文件本身，不要再额外套一层 `public` 文件夹。提交更改后，到 Render 发起部署。若 Render 的 Root Directory 已设为 `quban`，保持该设置不变。

## 运行
1. 安装 Node.js 18+（https://nodejs.org）
2. VS Code 打开本文件夹，终端执行：`npm start`
   （或按 F5；`npm run dev` 改代码自动重启）
3. 浏览器打开 http://localhost:3000

零依赖，不需要 npm install。

## 接上 AI（二选一）
**A. 免费、不用密钥（默认）**：安装 Ollama（ollama.com），终端运行 `ollama pull qwen2.5:3b`，之后趣伴自动使用，不用重启。
**B. 更聪明**：复制 `.env.example` 为 `.env`，填 `ANTHROPIC_API_KEY`，重启。填了密钥就优先用 Claude。

## 手机也能用
- 同一 Wi-Fi：手机浏览器打开 `http://电脑局域网IP:3000`，再「添加到主屏幕」。
- 外网使用需把项目部署到服务器（Render / Railway / 云服务器），代码无需改动。

## 目录
- `server.js` 后端：账号、好友、聊天(SSE 实时)、排行榜、AI 代理
- `public/app.js` 前端全部功能　`public/style.css` 样式　`public/logo.svg` Logo
- `data/db.json` 运行后自动生成的数据
