# Privacy 2.3.3

暖黄像素视觉版本，包含静态首启锁标动效、英文品牌字、账号验证与设置功能。

## 更新内容

- 首次冷启动显示一次锁扣合上的短动画；页面仍在后台时切回不重播。没有进度条或额外光效。
- 黄色 Privacy 锁标同步用于应用图标、网站图标和手机桌面图标。
- 聊天区采用暖白与黄色，设置里可以选择暖纸黄、奶油白或细像素点背景。
- 注册时验证邮箱和手机号；可通过已绑定的邮箱或手机号验证码找回密码。
- 设置包含通知预览、语言选项、联系方式绑定与账号删除。
- “输错密码后自动删除账号”默认关闭；启用后需要本人输入密码确认，并可设置错误次数。
- 浏览器脚本错误会关联请求码记录到服务器诊断日志。
- 未登录时显示登录入口；游客可浏览首页及精选离线小游戏，AI、好友聊天、备忘录、完整游戏和个人数据需登录。
- 登录可分别使用 Privacy ID、邮箱或国际手机号 + 密码；国家/地区区号由下拉选择。
- AI 状态可在聊天页查看。Render 必须配置 `GH_MODELS_TOKEN` 或 `ANTHROPIC_API_KEY`，否则模型无法回答。

## 运行

安装 Node.js 18 或更新版本，在项目根目录执行 `npm start`。根目录必须保留 `server.js`、`package.json` 和 `public/`。

邮箱和短信验证码需要配置服务商密钥，具体见 [验证码配置.md](验证码配置.md)。真实密钥只填写在 Render 的环境变量中，不要上传到 GitHub。

如需在 Render 长期保存账号、好友、消息和设置，请挂载持久磁盘并设置 `DATA_DIR=/var/data`。未配置持久磁盘时，平台重启可能清除本地 JSON 数据。
