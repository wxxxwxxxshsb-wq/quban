# Privacy 2.4.1 更新（在 2.4.0 基础上）

## 提速（针对“手机上很卡”）
- **打开应用**：以前要等 `/me`、`/settings` 两个请求依次返回才显示界面，服务器慢或刚醒时会白屏好几秒。现在先用上次的登录信息立刻显示，同时在后台校验；登录失效才会退回登录页。实测服务器响应慢（模拟 1.5 秒）时，从 3.1 秒缩到 0.14 秒。
- **缓存策略**：脚本、样式、图标改为缓存优先；页面本身最多等 2.5 秒联网，超时就先用缓存打开。
- **聊天列表**：先用缓存画出来，再后台刷新，不再每次切换都等两个请求。
- **绘制更省力**：气泡、头像、播放键的像素切角改成纯色阴影拼出来，去掉了对每条消息的滤镜和裁剪；手机上不再画背景点阵和悬停动画；输入框统一 16px，避免 iPhone 聚焦时自动放大；使用 `100dvh`，键盘和地址栏不再把布局顶乱。
- **手机版 / 电脑版分开**：`mobile.css` 只在手机宽度或触屏设备加载，`desktop.css` 只在宽屏且有鼠标时加载。手机版有页面滑入、底部弹层上滑，只用位移和透明度，由 GPU 直接合成。

## 表情包
- 新增“小鳄”：12 张原创像素贴纸（开心、大笑、爱心、哭哭、生气、睡觉、惊讶、酷、害羞、点赞、疑惑、谢谢），在聊天的贴纸面板里第一个标签。原来的 emoji 贴纸包保留。
- Telegram 的鳄鱼贴纸是第三方画师的作品，我无法下载，也不建议直接搬用；小鳄是为 Privacy 重新画的。

## 说明
- 我没法在真实 iPhone 上测帧率。上面的数字来自“手机尺寸 + 4 倍 CPU 降速”的模拟环境：滑动没有掉帧、打开聊天约 0.5 秒、切页约 0.15 秒。真机上如果仍有卡顿，请告诉我是哪一步，我再针对性处理。
- Render 免费实例休眠后首次唤醒本身就要几十秒，这是平台限制；本次改动让“已经打开过的用户”不再被这段时间卡住界面，但消息和好友数据仍要等服务器醒来才能刷新。

# 之前：Privacy 2.4.0 更新说明

## 怎么更新

1. 把这个压缩包解压，用里面的所有文件**覆盖**你 GitHub 仓库里的同名文件（保留你的 `.env`、`data/` 不要动，它们本来就不在仓库里）。
2. 提交并推送，Render 会自动重新部署。**不需要改任何环境变量，也不需要迁移数据**：旧消息会在启动时自动补上编号。
3. 部署完成后，用户端会自动更新（缓存名升到 `privacy-v16`）。如果某台设备仍显示旧界面，关闭后重新打开一次即可。

## 哪些功能直接可用

| 功能 | 说明 |
|---|---|
| 语音消息、印章、回复、转发、为所有人删除、屏蔽、阅后即焚、限时照片、好友请求 | 已由服务器实现，部署后即可用 |
| 应用锁、密室、隐私体检、主题与外观、免打扰、成就与回顾 | 前端本机实现，部署后即可用 |
| 备忘与提醒、收藏与文件、文档扫描（PDF）、提示词优化（本地模板）、语音转文字、全局搜索、定时发送、隐私联系卡 | 部署后即可用 |

## 依赖外部条件的功能

- **提示词优化（AI 模式）**：Render 已配置 `GH_MODELS_TOKEN` 或 `ANTHROPIC_API_KEY` 时自动用 AI；没配置就自动用本地模板，结果下方会标明用了哪种。
- **快捷翻译**：使用 MyMemory 免费服务，不需要密钥；每个用户每天约 5000 字，用完会提示。需要联网。
- **图片取字**：浏览器里用 Tesseract.js 识别，首次使用要从 CDN 下载中文识别包（约 20 MB），之后会缓存。需要联网。
- **语音转文字 / 语音附带文字**：依赖浏览器自带的语音识别（Chrome、Edge、Safari 可用，Firefox 不可用）。不支持的设备，入口会自动隐藏或换成别的功能。
- **扫一扫**：依赖浏览器的 `BarcodeDetector`（Chrome / Edge / 安卓可用）。iPhone 的 Safari 不支持，该按钮会隐藏；仍可用手机相机直接扫联系卡，会打开 Privacy 并请你确认添加。
- **录音、语音识别、相机**：浏览器要求 HTTPS（Render 默认是 HTTPS）。

## 已知限制（已在界面里写明）

- 提醒只在 Privacy 打开时弹出；网页无法在应用关闭后推送。
- 网页做不到屏蔽截图；聊天仍由服务器处理，没有端到端加密，请勿发送密码等敏感信息。
- 收藏的文件、扫描图存在本机浏览器里，换设备不同步，清除浏览器数据会丢失；单个文件 ≤ 10 MB。
- 阅后即焚只对设置之后的新消息生效；已有消息不受影响。
- Render 免费实例休眠时，定时发送和阅后即焚的清理可能延迟到唤醒后。
- 语音消息：iPhone 录制为 M4A，安卓 / 电脑为 WebM，双方都能播放；单条最长 5 分钟。
