# 把趣伴放到网上（约 10 分钟，免费）

做完后你会得到一个网址（形如 https://quban-xxxx.onrender.com），电脑、手机、朋友都能打开，不用装任何东西。

## 第 1 步：把代码放到 GitHub
1. 注册并登录 https://github.com
2. 右上角「+」→ New repository，名字填 quban，选 Public，点 Create repository
3. 在新页面点 “uploading an existing file”
4. 解压 quban-1.0.zip，进入 quban 文件夹，**选中里面所有文件和文件夹**（不是外面那个 quban 文件夹本身）拖进网页
   - 不要拖入 data 文件夹和 .env 文件（如果有）
5. 点 Commit changes

## 第 2 步：在 Render 部署
1. 打开 https://render.com，用 GitHub 账号登录
2. New → Blueprint（或 Web Service），选择刚才的 quban 仓库
   - Web Service 的话：Runtime 选 Node，Start Command 填 `node server.js`，实例类型选 Free
3. 在环境变量里填 GH_MODELS_TOKEN（免费 AI，见下面「免费 AI 令牌」）。ANTHROPIC_API_KEY 可以留空。
4. 点 Create / Deploy，等几分钟，页面上会出现你的网址

## 免费 AI 令牌（GitHub Models）
1. 登录 GitHub → 右上角头像 → Settings → 最下面 Developer settings
2. Personal access tokens → Fine-grained tokens → Generate new token
3. 名字随便填，有效期选长一点；权限里找到 Models，设为 Read-only（只读）
4. 生成后复制那串令牌，只显示一次。把它填到 Render 的 GH_MODELS_TOKEN
- 令牌等于密码，不要发给任何人（包括聊天里）。
- 免费有次数限制，用完要等一会儿；小伴默认用 openai/gpt-4o-mini（可用 GH_MODEL 改）。

## 第 3 步：手机安装
手机浏览器打开网址 → 菜单「添加到主屏幕」。

## 要知道的限制（免费版）
- 15 分钟没人用会休眠，下次打开要等几十秒唤醒。
- 免费版磁盘不持久：服务重启或重新部署后，注册的账号、好友、聊天记录会被清空。
  内测够用；正式给很多人用前要换成数据库（我可以帮你做）。
- 每人每天最多问小伴 50 次（AI_DAILY_LIMIT 可改）。GitHub 免费额度本身也有上限，人多了会提示稍后再试。
- 实时消息用的是 SSE 长连接，免费版是否稳定我没验证过；如果收不到，刷新页面即可看到。
