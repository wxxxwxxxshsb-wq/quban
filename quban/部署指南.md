# 趣伴 QuBan 2.2.2 更新和部署

## 上传更新到 GitHub

如果你的应用代码在仓库的 `quban/` 文件夹里：

1. 解压“趣伴2.2.2-GitHub更新文件.zip”。
2. 在 GitHub 打开仓库里的 `quban/` 文件夹，上传并覆盖 `server.js`、`package.json`、`README.md` 和 `.env.example`。
3. 打开仓库里的 `quban/public/` 文件夹，把更新包中的 `public` 文件夹打开，选中里面的文件上传并覆盖。不要把整个 `public` 文件夹再次放进 `public/`。
4. 提交更改。Render 通常会自动部署；也可以在 Render 的 `quban` 服务 → **Manual Deploy** → **Deploy latest commit** 手动部署。

## 让账号和聊天记录不再丢失

Render 免费 Web Service 的本地磁盘不持久。应用代码可以记住数据库放到持久磁盘，但必须先给服务配置持久磁盘：

1. Render 服务 → **Settings → Disks**，添加磁盘，Mount Path 填 `/var/data`。（Render 持久磁盘需要支持磁盘的付费实例。）
2. 服务 → **Environment**，新增 `DATA_DIR`，值填 `/var/data`。
3. 保存并重新部署。

仅上传代码、不配置持久磁盘，账号仍可能在服务重启或重新部署后丢失。已经被免费实例清掉的旧账号无法通过这次更新找回。应用不会在服务器保存明文密码，密码以加盐哈希保存。

## 安装到手机桌面

用手机浏览器打开应用网址，选择浏览器菜单里的“添加到主屏幕”。更新部署后重新打开一次，浏览器会更新 X 图标和启动动画。应用留在后台再切回来时不会重播；彻底划掉应用后，下次重新启动会播放。
