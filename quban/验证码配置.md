# 邮箱与短信验证码配置

验证码接口已经接入邮件和短信服务。为了避免把密钥写进代码，服务商账号信息必须放在 Render 的 Environment 环境变量中；不要把真实密钥上传到 GitHub。

## 邮箱验证码

使用 Resend：先验证一个发件域名并创建仅用于发信的 API key，然后在 Render 添加：

- `RESEND_API_KEY`：Resend API key
- `RESEND_FROM`：已验证域名下的发件地址，例如 `Privacy <verify@example.com>`

## 手机验证码

使用 Twilio Verify：创建 Verify Service，并在其控制台允许目标国家/地区后，在 Render 添加：

- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`
- `TWILIO_VERIFY_SERVICE_SID`

用户注册手机号要带国际区号，例如 `+8613800138000`。短信投递受国家/地区规则、服务商配置和运营商影响；Twilio 对中国大陆说明投递不保证，且需要检查 Verify 的国家权限。正式面向中国大陆用户前，请先用真实号码验证投递，必要时换用合规的境内短信服务商。

## 测试及安全

- 未配置服务商时，获取验证码会明确报错；不会把验证码显示在网页或日志里。
- 验证码有效 10 分钟，每个联系方式每小时最多申请 5 次，单个验证码最多校验 5 次。
- 邮箱验证码由本应用生成并经 Resend 发送；短信验证码由 Twilio Verify 生成及校验。
- 改密码、注册、绑定联系方式需要重新验证对应验证码。
- 账号邮件和手机号保存在应用的 JSON 数据库中；聊天内容也仍由应用服务器保存。请按自己的隐私要求评估服务商及托管位置。
